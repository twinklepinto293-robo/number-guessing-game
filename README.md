# number-guessing-game
A beginner Python number guessing game with limited attempts.

# Number Guessing Game 
This is a beginner Python project where the user tries to guess a randomly generated number within a limited number of attempts.
# Features
* Random number generation
* Limited attempts
* Hints (too high or too low)
* Simple and interactive gameplay

# What I learned
* Python loops and conditions
* Random module
* User input handling
* Game logic and debugging

# How to run
1. Download the project
2. Run the Python file:
   python number_guessing_game.py
